## Ce que je sais faire

### Bases
- Structure d'un programme Java : classe + `main`
- Compiler avec `javac`, exécuter avec `java`
- Variables, types primitifs (`int`, `double`, `boolean`, `char`), `String`

### Opérateurs
- Arithmétiques : `+ - * / %`
- Comparaison : `== != < > <= >=`
- Logiques : `&& || !`

### Conditions
- `if` / `else if` / `else`
- `switch` avec `case` / `default` / `break`

### Boucles
- `for`, `while`, `do-while`
- `break`, `continue`

### Tableaux
- Déclaration et parcours (`for`, `for-each`)
- Somme, moyenne, min, max, inverse

### Méthodes
- Déclaration `static type nom(params)`
- `void` vs `return`
- Surcharge
